# The Toaster Elevator

A two-line explanation of a toaster for a 10-year-old: a tiny elevator that carries one slice of bread down into a hot basement for two minutes and brings it back brown and crunchy — and an honest second line about what the elevator analogy maps and what it leaves out (there is no driver; a timer decides when the bread comes back up).
